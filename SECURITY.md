# Security Policy

## Reporting a vulnerability

Do not open a public issue for a security problem.

Report it privately to info@anointedcoder.com. If this repository has private vulnerability
reporting enabled, you can also use the Security tab and choose
"Report a vulnerability".

Please include:

- what the problem is and where it lives (file, endpoint, or page)
- the steps to reproduce it
- what an attacker could do with it
- any suggested fix

## What to expect

- We confirm receipt within 3 working days.
- We share an assessment and a target fix window within 7 working days.
- We disclose once a fix is released, and credit you unless you prefer otherwise.

## Scope

In scope: this repository's source code and its deployed application.

Out of scope: third party services, denial of service, spam, social
engineering, and findings that need physical access to a user's device.
